# ဗိုလ်တထောင် TV — Official Download Center

A bilingual (Burmese / English), mobile-responsive static website for Botahtaung TV Version 2.0. Built with plain HTML, CSS, and JavaScript; no build tools or dependencies are required.

## Publish on GitHub Pages

1. Create a **public repository** named `BotahtaungTV-Website` under `botahtaungonlinestore`.
2. Upload **the contents of this folder** (not the ZIP file itself) to the repository's root. Make sure `index.html`, `README.md`, and the `assets/` folder are visible in the root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. When deployment finishes, the expected website address is:
   `https://botahtaungonlinestore.github.io/BotahtaungTV-Website/`

GitHub Pages may take several minutes to publish the first deployment.

## Included

- Responsive design for phones, tablets, desktops, and TV browsers
